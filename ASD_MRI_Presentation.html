Introduction

Why machine learning on structural MRI?

  • Autism Spectrum Disorder (ASD) is a neurodevelopmental condition; early, objective detection supports timely intervention.
  • Diagnosis today relies on behavioral assessment — subjective, time-consuming, and variable between clinicians.
  • Structural MRI captures subtle neuroanatomical differences associated with ASD.
  • Machine learning can learn patterns in MRI that are difficult to observe directly.
  • Goal: an automated classifier that outputs P(ASD) for each scanned patient.

Project objectives

  • Combine deep and handcrafted image features
  • Add approved clinical inputs (age, sex, FIQ)
  • Patient-level classification — one decision per person
  • Rigorous, reproducible evaluation protocol

Preprocessing

Standardizing every scan

StepSpecification
OrientationCanonicalize every scan to RAS
ResamplingAxis-aligned 1 mm isotropic grid (linear image / nearest mask)
Brain maskForeground from skull-stripped voxels, re-applied after resampling
NormalizationPer-patient in-mask 1st–99th percentile → clip [0, 1]
Slice selection9 slices × axial / coronal / sagittal, central 20–80% extent
Quality gates≥ 256 brain pixels/slice; failures reported explicitly
CNN inputAspect-preserving letterbox → 224 (B0) / 456 (B5)

Design choices

  • Fresh processing from original scans — no stale caches
  • Slices sampled across axial, coronal and sagittal anatomy
  • Intensity scale normalized inside the brain mask only
  • Deterministic recipe — identical pipeline for every scan
Deep features

EfficientNet embeddings

Transfer learning from ImageNet
  • Pretrained EfficientNet as a fixed feature extractor (B0 first, B5 compared).
  • Classifier head removed → global convolutional embedding per slice:
  • 1,280 dimensions (B0)  ·  2,048 dimensions (B5)
  • 27 slices per patient (9 × 3 views) → mean + std pooled per view:
  • 7,680 (B0) / 12,288 (B5) deep features per patient
  • Fold-local standardization + PCA → 128 compact deep features.
  • Grayscale replicated to 3 channels, ImageNet mean/std normalization.

Why EfficientNet?

  • Compound-scaled architecture — strong accuracy per parameter
  • ImageNet features transfer well as generic image descriptors
  • Frozen encoder → reproducible, fast, no GPU-heavy training
  • Two sizes compared fairly on the same folds
Handcrafted + clinical

Interpretable descriptors

GLCM texture

  • Contrast · dissimilarity · homogeneity · ASM · energy · correlation · entropy
  • 32 levels, distances 1/2/4, four angles, brain-mask pairs only → 42 / slice

LBP texture

  • Uniform LBP at radii 1/2/3 (P = 8/16/24), in-mask centers → 54 / slice
  • Mean + std pooled per view → 576 per patient

Clinical inputs

  • Age · sex · Full-scale IQ (FIQ)
  • Three explicit missingness flags; median imputation
  • Allowlisted fields only — no site, ID, or diagnostic scores

Combined predictor

128 deep (PCA)  +  576 texture  +  6 clinical  =  710 features per patient
Classifier

Random Forest

Ensemble of 500 decision trees
  • 500 trees, bootstrap sampling, class_weight = balanced_subsample.
  • Hyperparameter search (8 candidates) over:
  • max depth · min samples per leaf · max features · max samples
  • 5 outer × 3 inner cross-validation folds for model selection.
  • Decision threshold tuned on inner out-of-fold probabilities.
  • Ablations trained on identical folds: MRI-only, deep-only, texture-only, clinical-only.

Why Random Forest?

  • Handles heterogeneous feature scales well
  • Robust to overfitting on moderate cohorts
  • Calibrated class probabilities → tunable threshold
  • Feature-importance analysis is straightforward
  • Well-suited to fusing deep + handcrafted + clinical blocks
Evaluation

How the model was measured

Patient-level split

  • 803 development / 201 test patients, stratified by site and label
  • All slices of a patient stay together — evaluation is per person
  • Test set evaluated once, after the models were frozen

Metrics

  • Accuracy, sensitivity, specificity, balanced accuracy, precision, F1
  • ROC-AUC, PR-AUC, confusion matrix, 95% confidence intervals

Reproducibility

  • Fixed seed (42) — deterministic splits and models
  • Frozen model bundles reproduce recorded predictions exactly
  • Feature and weight fingerprints verify cache validity
  • 163 automated regression tests
  • Full run artifacts and report preserved (runs/hybrid/r2)

Observations

  • Combining all three sources gives the best result.
  • Texture and deep features are complementary — each adds signal.
  • Clinical inputs alone are weak; MRI carries the decision.
  • B0 outperformed B5 — the larger model did not help at this cohort size.
Conclusion

Summary & future work

  • Built a complete hybrid ASD classifier: EfficientNet embeddings + GLCM/LBP texture + clinical → Random Forest.
  • Achieved 71.6% patient-level accuracy and 0.82 ROC-AUC on the held-out test set.
  • The full pipeline — preprocessing, features, model, evaluation — is reproducible and fully tested.
  • Future directions:
  • Supervised fine-tuning of the encoder on development patients
  • 3-D / volumetric encoders or medical-imaging pretrained backbones
  • Gradient boosting / calibrated ensembling
  • Larger multi-cohort data and external-site validation
